AIDE / Android Java notes

- Native Java/XML source; package: com.screenassist.launcher.
- Minimum SDK 23; target SDK 32; project.properties targets Android SDK Platform 32.
- TensorFlow Lite 2.14.0 is required. Run `sh scripts/setup_aide_tflite.sh` to download the official Maven Central AAR and its separate API JAR.
- The setup script extracts libs/tensorflow-lite.jar, installs libs/tensorflow-lite-api.jar, and extracts the arm64-v8a JNI runtime under jni/.
- The Galaxy Note10+ uses the arm64-v8a ABI. The matching libtensorflowlite_jni.so must be packaged in the APK; a Java JAR alone is not a complete runtime.
- The Gradle build uses the Maven dependency, which resolves its API dependency transitively.
- Model installation is a separate step and is not included in this runtime-library setup.
- The app processes only images explicitly selected by the user. No MediaProjection, foreground capture service, game package lookup, or floating overlay code is included.
