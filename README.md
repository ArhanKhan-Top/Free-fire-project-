# Screen Assist — Offline Image Annotator

Native Android Java/XML app for selecting a local image, running TensorFlow Lite object detection, viewing confidence-labelled boxes, and saving an annotated PNG.

- Uses the Android document picker; no screen capture or floating overlay.
- Generic EfficientDet-Lite0 COCO model; not specialised for game characters.
- See `ScreenAssistLauncher-offline/README.md` for build and model setup.
